# Ceptuves mājaslapa (Valērijs Voroņko)
Projekta mērķis – izveidot dinamisku ceptuves tīmekļa lapu ar formu un datu glabāšanu Supabase datubāzē.

## Izmantotās tehnoloģijas
- HTML5 / CSS3 / SASS
- JavaScript (Supabase integrācija)
- GitHub versiju kontrole

## Funkcionalitāte
- Pasūtījuma forma ar datu sūtīšanu uz Supabase
- Animācijas (reveal, parallax, hover efekti)
- Responsīvs dizains
